# SportyGo

**SportyGo** is a mobile application built with **React Native and Expo** that helps people connect with sports groups and easily organize games and activities. The app is designed for both **iOS and Android** and is currently in the **testing phase** with a small group of users.

## Features

- **Discover Sports Groups:** Browse and join local teams, clubs, or pickup games.  
- **Create and Manage Groups:** Organize your own sports events and invite others to participate.  
- **Schedule Coordination:** Simplify event planning with built-in scheduling features.  
- **Connect with Players:** Communicate and coordinate directly with other participants.  

## Tech Stack

- **Frontend:** JavaScript / TypeScript, React, React Native, Expo  
- **Backend:** Firebase Firestore  
- **Authentication:** Auth0  
- **Platforms:** iOS & Android (currently in beta/testing)  

## Status

- Currently in **testing** with 10–12 active testers.  
- Gathering feedback to improve usability and add new features before public release.  

## Roadmap

- Push notifications for group events  
- Enhanced matchmaking to connect players based on availability and skill level  
- Expanded social and community features  

## About

SportyGo was created to make organizing sports activities simple and to help people build local communities around the sports they love.
